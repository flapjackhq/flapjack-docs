## What is Flapjack?

- **Algolia-compatible API** — same REST paths, same auth headers, same response format. Point your existing Algolia client at Flapjack and it works.
- **Self-host anywhere** — single binary, zero dependencies. `docker run` or download and run.
- **Built on Rust + Tantivy** — fast full-text search with sub-millisecond query times.
- **Flapjack Cloud** — don't want to manage servers? Flapjack Cloud runs Flapjack for you with zero ops. Free up to 3 indices, 100,000 records, 250 MB storage, and 50,000 searches/month — no credit card required. Beyond the free tier, storage is metered at $0.05/MB/month.
